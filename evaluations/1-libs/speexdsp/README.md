# SpeexDSP 1.2.1 validation (TLC Only) [ALL TESTS PASSED]

[中文版](README.zh-CN.md)

Public commands use the repository-local `.work/devkit` by default. Set `LORELEI_DEVKIT=/absolute/path/to/devkit` to override it.

This recipe installs the official SpeexDSP 1.2.1 shared library and all five test programs supplied by the release. It generates one TLC thunk and executes the same programs against the native AArch64 DSO and through Hecate against that DSO. It does not load HLR extensions or run a pure QEMU lane.

## Commands

```bash
./evaluations/1-libs/speexdsp/run.sh
./evaluations/1-libs/speexdsp/run.sh --reference --verbose
./evaluations/1-libs/speexdsp/run.sh --install-only
```

Set `QEMU=/path/to/qemu-x86_64` when the patched emulator is not installed in the devkit.

## Installed upstream tests

The upstream release has no registered `make check` suite. Its `libspeexdsp/Makefile.am` instead declares five `noinst_PROGRAMS`, and the overlay installs all five under `tools/speexdsp/upstream-tests/bin`:

1. `testdenoise` processes four deterministic 8 kHz PCM frames.
2. `testecho` processes deterministic microphone and reference PCM files.
3. `testjitter` exercises packet insertion, retrieval, reset, tick, and frozen-sender recovery.
4. `testresample` converts four deterministic PCM frames through the floating-point resampler.
5. `testresample2` sweeps output rates from 1 kHz through 128 kHz.

Success requires zero exit status for all five programs in both lanes. The deterministic denoise, echo, jitter, and stream-fed resample outputs must match byte for byte across lanes. The internally generated floating-point `testresample2` output is checked for a matching nonzero size because its input sine wave is computed by the native or guest libm before entering the shared DSO.

The port deliberately disables SSE and NEON so both lanes evaluate the same portable SpeexDSP implementation. Test inputs and executables are installed or generated by the recipe. No source-tree rebuild occurs after vcpkg installation.
