# Function coverage audit

This evaluation passes the complete dynamic function export set of each measured DSO to TLC and records the functions that TLC can resolve from the complete upstream headers. It does not use the API allowlist of a command-line workload.

Run it with:

```bash
python3 evaluations/3-breakdown/coverage-effort/run.py
```

The raw Symbols file, aggregate Desc, TLC command, log, and `ThunkStat.json` are stored under `results/<run-id>/libraries/`. `summary.csv` records the exported, Hecate-supported, and unsupported function counts and the resulting coverage for each DSO.

`evaluations/export-paper-data.py` counts the manually maintained configuration separately. That metric includes include lines in reviewed configuration files and excludes the Symbols, aggregate Desc, and thunk sources generated by this audit.
