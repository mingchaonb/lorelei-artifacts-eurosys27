# Function coverage audit

This evaluation compares Hecate and Box64 function coverage and manual configuration effort across 20 actual DSOs. It passes the complete dynamic function export set of each DSO to TLC and records the functions that TLC can resolve from the complete upstream headers. It does not use the API allowlist of a command-line workload.

The evaluated set contains:

- Compression libraries: zlib, zstd, bzip2, Brotli, and LZMA
- Multimedia libraries: FFmpeg avformat, avcodec, and avutil, plus Ogg, Opus, and libsndfile
- Graphics and window system libraries: SDL2, Vulkan, OpenGL, X11, and XCB
- General system libraries: Expat, curl, libevent, and IDN2

Run it with:

```bash
python3 evaluations/3-breakdown/coverage-effort/run.py
```

The raw Symbols file, aggregate Desc, TLC command, log, and `ThunkStat.json` are stored under `results/<run-id>/libraries/`. X11, XCB, Vulkan, and OpenGL reuse the complete export audits installed by their ports and record the source of that evidence. `summary.csv` records the exported, Hecate supported, and unsupported function counts and the resulting coverage for each DSO.

`evaluations/export-paper-data.py` counts the manually maintained configuration separately. That metric includes include lines in reviewed configuration files and excludes the Symbols, aggregate Desc, and thunk sources generated by this audit. Box64 manual LOC also includes `GO`, `GOM`, `GO2`, `GOW`, `GOWM`, `GOS`, and data-wrapper declarations disabled with `//`, because they are manually maintained work. They are included directly in `box64_manual_loc` but do not enter Box64's supported-function set for coverage. Ordinary prose comments remain excluded from LOC.
